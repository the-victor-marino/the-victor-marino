## Featured QA project

### [iGaming RTP QA Pipeline](https://github.com/the-victor-marino/igaming-rtp-qa)

A Python slot-model project that turns testing into reproducible evidence:

- **Game rules:** payout calculations, invalid inputs and session loss-limit boundaries.
- **Wallet integrity:** integer-credit balances and concurrent bets.
- **Statistical checks:** theoretical versus simulated RTP, symbol frequencies and RNG risk experiments.
- **Reporting:** automated tests, GitHub Actions artifacts and a self-contained HTML QA report.

**Stack:** Python · pytest · NumPy · GitHub Actions

*Portfolio model with documented limitations; not a certified game or RNG audit.*
